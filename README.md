# LiveExpedition 0.3.4-preview

`main` の v0.3.1-preview を基準とした、ホーム・残高・収支・口座・クレジットカード・サブスクの改修です。作業ブランチは `feature/home-balance-v034`。ライブ・遠征の既存経路を保持しています。

## データと更新

- アプリIDは `jp.local.liveexpedition.preview`、versionCode は 7。同じ既存開発鍵で更新APKを署名します。鍵はリポジトリに含めません。
- Roomスキーマv1、SQLCipher、Keystore、画像・バックアップ暗号化を継続。破壊的マイグレーションはありません。新しい種類・項目は既存のJSONレコードに保存します。
- 初回起動・旧バックアップ復元時、既存会計記録へメイン口座と保存順を追加します。ID・画像・支払リンク・金額・過去の日付は保持します。DBトランザクション内で検証して移行します。
- INTERNET権限は追加していません。銀行・カード・サービスの外部照会や解約は行いません。

## 残高・カード

現在残高は実際の口座残高、クレジット反映後残高は現在残高から全期間の未引落しカード利用を引いた参考値です。カード利用は利用月の支出に含め、引落しは支出集計から除外します。予定日が過ぎても自動では引落し済みにしません。カード画面で対象利用と実際の引落し日を選んで確定します。

「残高を設定」は各口座の実残高を設定時点で確定します。古い通常取引を再計算しません。以後に保存された同日以降の取引だけを反映し、過去日付を後から追記しても設定額から再度差し引きません。月別集計と未引落し債務は保持します。履歴は削除・編集せず、必要なら再設定します。

口座は初期1つ・最大2つ。設定で追加・改名し、全口座合計も確認できます。カードの引落し口座を変更した場合、未引落し債務は新しい口座側に表示します。過去の確定引落し口座は保持します。新規振替はなく、旧振替履歴はそのまま残します。

カードは締め日、引落し日、締め月から0〜2か月、休日ルールを設定できます。存在しない日は月末。土日を翌月曜に送るか暦日のままにするか選べます。祝日・銀行営業日は推測しません。個々の利用の予定日を手動変更してください。旧データの「クレジットカード」という支払方法だけではカードを特定できないため、既存の実残高の扱いを維持します。カード選択済みの新規利用から債務として区別します。

## 入力・ダッシュボード

フォームは画面種別・レコードID別に暗号化して自動保存し、自然に復元します。新規支出・収入・関連先や編集セクションも区別します。登録時・明示破棄時だけ対象下書きを削除します。設定の「入力の自動保存」で一覧から再開・破棄できます。最大64件・合計4MiB。上限時は既存入力を消さず保存エラーを表示します。同じ記録の別編集が先に確定した場合、古い下書きによる上書きを拒否します。不要な古い下書きを破棄して開き直してください。

ホームと残高は独立したタイル配置です。長押しでドラッグ、動かさず離すとサイズ・非表示・内容を変更できます。＋で表示を選び、変更直後は取り消せます。チャコールと薄いカテゴリ色、状態ラベルを使用します。目アイコンと全体マスクは共通で、同じ請求予測は同じ表示設定を使います。入力フォームとメモは自動マスクしません。

## サブスク

サブスクは請求予測のみ。実際の取引やカード債務を生成しません。月額は請求日、年額は月日と前回請求日を設定でき、月末・年越し・うるう年を扱います。前回請求日を選ぶと請求月日もその日付に合わせます。その後に月日を個別調整できます。次回日付の手動変更も可能です。

ホームは対象月の請求予測額を優先し、残高の小タイルは「サブスク管理」のみ。詳細の請求情報・登録内容カードをタップして編集します。月ごとの支払済み・未払い管理は追加しません。

解約予定日より後の予測を止め、予定日を過ぎてアプリを開くと「削除／あとで」を表示します。「あとで」はその日だけ抑止します。自動削除はしません。「削除」はサブスクをアーカイブし、過去の取引・支払リンク・カード債務を保持します。外部サービスの実際の解約は別途必要です。
