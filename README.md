# LiveExpedition 0.3.1 preview

既存Androidアプリを、添付の総合是正指示書に沿って更新しました。Android 13以降、日本語、Kotlin / Compose / Material 3 / Room / DataStoreを継続しています。

## 配布物

- `../LiveExpedition-v0.3.1-preview.apk`：非デバッグの更新APK。
- `../LiveExpedition-v0.3.1-AndroidStudio.zip`：ソース、モデル、ライセンス、検証記録を含むAndroid Studioプロジェクト。
- `../LiveExpedition-v0.3.1-UI-preview.png`：開発用データをRobolectricのAndroid描画環境で描いた画面。実機写真ではありません。
- [実装状況と制限](STATUS.md)、[保護と検証範囲](SECURITY.md)、[変更ファイル](reports/v0.3.1/changed-files.md)。最終結果は `reports/v0.3.1/verification-summary.json`。

## 更新とデータ

既存版をアンインストールせずAPKを更新します。同じアプリID `jp.local.liveexpedition.preview`、同じ開発証明書を使用し、versionCodeは3→4です。Roomのスキーマv1は変更していません。新項目は既存JSON payloadに保存します。破壊的Migrationはありません。既存の名称だけのアーティスト・ツアーは、そのまま階層に表示します。自動で一括書換えは行いません。

アプリID・証明書・スキーマの一致は静的比較しています。旧APKからの実機更新は未検証です。必要な既存データは先にアプリの暗号化バックアップで保存してください。更新が失敗した場合、削除して入れ直すと内部データ・Keystore鍵が失われます。

配布APKは以前と同じ開発鍵による署名です。正式配布鍵への移行は今回の範囲に含みません。署名鍵はZIPに含みません。別環境で生成するdebug鍵によるビルドでは、そのまま更新できない場合があります。

## 操作

ホームは「今日／予定一覧／カレンダー」。タイルを長押しして動かし、離すと並び順を保存します。指を置いた位置を維持し、移動前の安定したグリッドを基準に入替先を判定します。範囲外やキャンセルでは復帰します。動かさず長押しして離すと、4サイズ・内容・非表示の設定を開きます。＋で追加できます。配置変更には「元に戻す」があります。

予定一覧は未来の日付へ移動でき、カレンダーから日を選べます。公演、採用遠征の区間、予定、申込・支払・予約期限を元レコードから表示します。現在の予定、重複選択、手動固定、夜行便、乗り換え展開に対応します。運行情報・GPS・遅延の取得は行いません。

ライブはアーティスト→ツアー・イベント→公演→複数の受付です。単発公演はツアーを空欄にします。既存名称は再登録せず表示されます。登録は基本情報・日時・詳細に分けています。画像から読み取る場合は端末内OCRを使用し、原文と候補を確認・修正して入力欄へ反映し、最後に保存します。OCRが読み取れない項目は手入力します。

遠征は種類を選んで入力し、複数区間を追加できます。長押しした位置を保って既存／新規プランへドロップできます。費用・時間・乗換・未入力・未予約を比較し、採用プランを予定へ反映します。1プランに複数公演を関連付けられます。

残高をタップすると初期残高・調整履歴を開きます。調整は独立した履歴で、過去の取引を書き換えません。月別の収入・支出、カテゴリ集計、予算、サブスクを確認できます。カテゴリの管理は登録時の選択画面内です。申込・当選・予約・サブスク換算だけでは支出を生成しません。実際に支払った場合に「支払を記録」を使います。

金額の目アイコンは項目ごとに表示を切り替え、設定の「すべての金額を隠す」は全体をマスクします。自由記述や入力フォームは自動マスクしません。

下部タブは通常タップと長押しスライドに対応します。長押しスライドは初期ON、画面スワイプによるタブ切替は初期OFFです。子の横スクロール・タイル操作とOS端部の操作を優先し、先頭末尾は循環しません。設定で独立して切り替えられます。

設定は表示・ナビゲーション・ホーム・認証・データ管理に分けました。テーマはシステム／ライト／チャコール／ブラック、アクセントは3色。アプリロックは初期ON、OFFには確認があります。OFFでも暗号化を維持します。下書きは1件を端末内で暗号化し、閉じた後は再開／破棄できます。

## ビルド

JDK 21、Android SDK platform 36 / build-tools 35.0.0、Gradle wrapper 8.13を使用します。SDK位置は各環境の `local.properties` または `ANDROID_HOME` で設定します。SDK・JDK・キャッシュ・署名鍵はZIPに含めません。初回の開発ビルドには依存取得の通信が必要ですが、AndroidアプリはINTERNET権限を持ちません。OCRの日本語・英語モデルは同梱済みです。

```text
gradlew testDebugUnitTest testReleaseUnitTest assembleRelease assembleDebugAndroidTest lintRelease runtimeInventory
```

ロジック・UI自動テストとリリースビルドの結果を同梱しました。実端末の認証、更新、DB・SAF、通知、OCRのJNI起動・認識精度、操作感の受入は残っています。
